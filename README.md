# Instructivo de replicabilidad

Este repositorio contiene los archivos, scripts y datos necesarios para reproducir el flujo de trabajo del proyecto.

## Estructura general

- **`/docs`**: contiene la guía del proyecto y la descripción general del flujo de programas.
- **`/scripts`**: contiene los scripts mencionados en la guía, junto con su uso correspondiente.
- **`/data`**: almacena los datos generados a partir de la ejecución de los scripts.
- **Demás carpetas**: contienen los archivos propios de cada programa utilizado dentro del flujo del proyecto.

## Flujo general

1. Consultar la guía del proyecto en la carpeta **`/docs`**.
2. Ejecutar los scripts correspondientes ubicados en **`/scripts`**.
3. Los datos generados por estos scripts se almacenan en la carpeta **`/data`**.
4. Las demás carpetas contienen archivos auxiliares, configuraciones o resultados específicos de cada programa.

## Nota

Se recomienda seguir el orden y las instrucciones descritas en la guía ubicada en **`/docs`**, ya que allí se documenta el flujo completo del proyecto y el propósito de cada script.
